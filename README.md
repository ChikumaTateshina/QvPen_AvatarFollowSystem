# QvPen_AvatarFollowSystem

QvPen follows the avatar.

## Install

**[Add to VCC / 導入方法](https://chikumatateshina.github.io/QvPen_AvatarFollowSystem/)**

Open the page above and press "Add to VCC", or add this repository URL to VCC / ALCOM by hand:

```
https://chikumatateshina.github.io/QvPen_AvatarFollowSystem/index.json
```

Then add **QvPen Avatar Follow System** to your world project and drag `Prefab/QvPen_AvatarFollowSystem.prefab` into the Hierarchy. [QvPen](https://github.com/ureishi/QvPen) must already be installed in the world.
